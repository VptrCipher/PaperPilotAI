# Demonstration paper

`fair-principles.pdf` is the published open-access Comment by Mark D. Wilkinson, Michel Dumontier, I. Jsbrand Jan Aalbersberg, and colleagues, “The FAIR Guiding Principles for scientific data management and stewardship,” *Scientific Data* 3, 160018 (2016). It presents community-developed principles, so the model should describe its workshop and examples in terms suited to a principles paper.

- [Article and license notice](https://doi.org/10.1038/sdata.2016.18)
- [Publisher PDF from Erasmus University Rotterdam](https://pure.eur.nl/ws/portalfiles/portal/47734463/sdata201618.pdf)
- [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

The bundled PDF is an unmodified copy from the repository, including its cover sheet on PDF page 1. Generated outputs use one-based physical PDF pages.

Run `python -m sample_data.setup_embeddings` from the project root to download the separate embedding model.
